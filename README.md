# Rudiment Lab

Бесплатный тренажёр рудиментов для барабанщика: метроном, 59 паттернов, режим «Установка» (бочка, хет, крэш), Auto BPM, рекорды темпа, план на сегодня, календарь практики. Без рекламы и подписок, данные хранятся на телефоне.

## Как получить APK

1. Создай пустой репозиторий на GitHub (например `rudiment-lab`).
2. Залей в него этот проект:
   ```bash
   git remote add origin https://github.com/<ты>/rudiment-lab.git
   git push -u origin main
   ```
3. Открой вкладку **Actions**: сборка `Build APK` стартует сама (5–10 минут).
4. Готовый файл лежит в **Releases → «Rudiment Lab — последняя сборка»** (`RudimentLab.apk`). Скачай на телефон и установи (Android попросит разрешить установку из браузера).

Каждый новый `git push` в `main` пересобирает APK. Подпись фиксированная (`ci/debug.keystore`), поэтому новая версия ставится поверх старой с сохранением истории.

## Без APK

`www/` — обычный статический сайт. Можно включить GitHub Pages на папку `www` или просто открыть `www/index.html` в браузере; на телефоне «Добавить на главный экран».

## Свои паттерны

Все паттерны в `www/patterns.js`, формат описан в комментарии в начале файла. Добавить свой — одна строка:

```js
add('kit', 'Мой грув', 'H+K H H+S H H+K K H+S H', { div: 2, bpm: 90, note: 'Описание' });
```

Токены: `R L` руки, `S` малый, `K` бочка, `H` хет, `X` крэш, `fR` флэм, `dR` драг, `R~` бузз, `H+K` одновременно, `-` пауза. Заглавная буква — акцент.

Стикинги рудиментов набраны по памяти по стандартному списку PAS; если какой-то отличается от твоего учебника, поправь строку в `patterns.js`.
