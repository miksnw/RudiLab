# Rudiment Lab

Бесплатный тренажёр рудиментов для барабанщика: метроном, 59 паттернов, режим «Установка» (бочка, хет, крэш), Auto BPM, рекорды темпа, план на сегодня, календарь практики. Без рекламы и подписок, данные хранятся на телефоне.

## Как получить APK

1. Создай пустой репозиторий на GitHub (например `rudiment-lab`).
2. Залей в него этот проект:
   ```bash
   git remote add origin https://github.com/<ты>/rudiment-lab.git
   git push -u origin main
   ```
3. Открой вкладку **Actions**: сборка `Build APK` стартует сама (5–10 минут).
4. Готовый файл лежит в **Releases → «Rudiment Lab — последняя сборка»** (`RudimentLab.apk`). Скачай на телефон и установи (Android попросит разрешить установку из браузера).

Каждый новый `git push` в `main` пересобирает APK. Подпись фиксированная (`ci/debug.keystore`), поэтому новая версия ставится поверх старой с сохранением истории.

## Без APK

`www/` — статический сайт на ES-модулях, поэтому `index.html` нельзя открыть двойным кликом (браузер блокирует модули с `file://`). Запуск локально:

```bash
npm run serve        # откроет http://localhost:8080 (без зависимостей)
```

Или включи GitHub Pages на папку `www`; на телефоне «Добавить на главный экран».

## Устройство кода

```
www/src/
  core/      dom (h), time, store (localStorage), stats, services (общий store)
  data/      patterns.js (библиотека паттернов), challenges.js (готовые челленджи)
  audio/     scheduler (чистая логика ритма), voices (звуки), ticker (Worker-таймер),
             visual (подсветка), engine (склейка), render (офлайн-рендер для замеров)
  import/    zip, gpif (.gp), midi, quantize — файл → партия
  notation/  staff.js — нотный стан (SVG)
  ui/        state (S, go), kit (компоненты), session (темп/Auto BPM/челлендж),
             pattern/ (layout, tiles, экран), screens/ (практика, сегодня, записи, челленджи, импорт)
www/style/   tokens (цвета) · base · components · pattern (плитки, темп)
```

Правила: логика (`core`, `audio/scheduler`, `import`, `ui/session`, `ui/pattern/layout`) не трогает DOM и тестируется в Node; DOM собирается только через `h()` и компоненты из `ui/kit.js`. Поменять вид — правь `style/tokens.css` и `style/components.css`; новый экран — файл в `ui/screens/` и строка в `ui/app.js` + `ui/nav.js`.

## Тесты и замер тайминга

```bash
npm test                              # юнит-тесты (node:test), без зависимостей
npm run test:e2e                      # браузерные: нужен Playwright (npm i -D playwright)
```

Точность метронома: открой `http://localhost:8080/dev/timing.html` (на телефоне — по адресу компьютера в локальной сети) и нажми «Запустить замер». Офлайн-часть показывает ошибку самой логики (должна быть сотые доли мс), живая — дрожание таймера, запас до звука и опоздание подсветки на твоём устройстве, в том числе под искусственной нагрузкой. Если в строке «шагов с нулевым запасом» не 0 — звук на этом устройстве может заикаться, увеличь `LOOKAHEAD_SEC` в `audio/scheduler.js`.

Поправка подсветки относительно звука (если на Bluetooth-наушниках кадр опережает звук): `settings.visualOffsetMs` в данных приложения.

## Свои паттерны

Все паттерны в `www/src/data/patterns.js`, формат описан в комментарии в начале файла. Добавить свой — одна строка:

```js
add('kit', 'Мой грув', 'H+K H H+S H H+K K H+S H', { div: 2, bpm: 90, note: 'Описание' });
```

Токены: `R L` руки, `S` малый, `K` бочка, `H` хет, `X` крэш, `fR` флэм, `dR` драг, `R~` бузз, `H+K` одновременно, `-` пауза. Заглавная буква — акцент.

Стикинги рудиментов набраны по памяти по стандартному списку PAS; если какой-то отличается от твоего учебника, поправь строку в `patterns.js`.

## Вкладка «Челленджи» (β)

- **Готовые**: рудимент или грув + цель по темпу. Темп растёт сам, челлендж засчитан, когда ты сыграл фразу на целевом темпе.
- **Свой**: любой паттерн из библиотеки со своими стартом, целью, шагом и числом повторов.
- **Партия из файла**: загрузи Guitar Pro 7/8 (`.gp`) или MIDI (`.mid`), выбери ударную дорожку и такты (до 4). Получится упражнение с темпом, зацикливанием и Auto BPM.
  - Вид «Плитки»: H S K T1 T2 T3 C R, плитки одного шага стоят столбиком (хет сверху, бочка снизу).
  - Вид «Ноты»: стандартная барабанная нотация (паузы пока не рисуются).
- Форматы `.gp3/.gp4/.gp5/.gpx` пока не читаются: сохрани файл как `.gp` или экспортируй в MIDI.
